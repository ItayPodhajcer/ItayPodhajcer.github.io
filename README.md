# Itay Podhajcer's Blog

Source for [itaypodhajcer.com](https://itaypodhajcer.com) — Itay Podhajcer's personal technical blog,
covering hands-on articles on Azure, blockchain/Web3, DevOps, AI, and software architecture. Most
posts were originally published on [Medium](https://medium.com/@itaypodhajcer) and imported here,
which is now the canonical home.

The site is a static [Astro](https://astro.build) build, hosted on GitHub Pages.

## Tech stack

- **[Astro 6](https://astro.build)** — static site generator with type-safe content collections.
- **[Tailwind CSS v4](https://tailwindcss.com)** — styling, via the `@tailwindcss/vite` plugin.
- **[Expressive Code](https://expressive-code.com)** — code-block syntax highlighting (light/dark themes, line numbers, copy button).
- **[Pagefind](https://pagefind.app)** — fully client-side search over the built site.
- **RSS & sitemap** — generated at build time via `@astrojs/rss` and `@astrojs/sitemap`.
